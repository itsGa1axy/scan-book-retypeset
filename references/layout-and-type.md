# 布局与字体

## 页面坐标

使用统一工作坐标，例如显示页左上角为原点、x 向右、y 向下，单位为 PDF point。保留从 PDF 原始坐标、图像像素坐标和 OCR 坐标到该坐标的变换。

1. 同时考虑 CropBox、页面旋转、非零原点、UserUnit 和图像放置矩阵；不只用 `像素 / dpi × 72`。
2. 页面可能横纵缩放不同；只在源放置矩阵确实如此时保留该变换，不能随意拉伸图片去填满目标框。
3. 每次裁切或降采样都记录新原点与比例；对照一个已知文字/图像角点验证变换。
4. 重建几何先在正确画布上完成；不靠最后整体缩放来掩盖内容越界。

本次实践的教训：插入色带时，库默认保持宽高比可能悄悄缩窄色带。必须检查实际矩阵与目标矩形；源的横纵缩放已经确认时才允许非等比映射。

## 文本定位层级

默认顺序：段落区域排版 → 保留原换行的行级定位 → 局部字距调整 → 必要区域逐字定位。逐字定位不能替代所有排版：它可能破坏连写、组合字符、连字、复制顺序和一致字距。

- 保存视觉换行与逻辑段落两种信息；用户要求同版时保持视觉换行，不为了纯文本美观重排正文。
- OCR 的 `bbox` 可能近似字宽、字墨迹或整个字槽；用渲染校准含义，不假定它就是字体 advance。
- 一行内使用一致字号和合理基线；不要把 OCR 的逐字高度变化直接转成真实字号变化。
- 字体墨迹框、advance、ascender/descender、em 方框彼此不同；确认当前库的 glyph bbox 是否实际返回全字体边界。
- CJK 句号、逗号、引号等的 OCR 框常很窄，按完整 em 方框居中可能把标点压进前一字。单独校准墨迹位置与标点压缩。
- 标题与章节号间的空隙有时在 OCR 中丢失；用实际版面恢复层级间距，不能只把拼接字符串均匀展开。
- 目录斜杠、页码、罗马数字、点线引导符和章节标题分别定位；页码必须对照原图，不由正文位置推算覆盖原数值。

## 字体策略

按正文/标题/目录/引用/脚注/数字/公式建立样式，记录字体文件、字体集合索引、PostScript 名、字重与实际字号。字体集合的第一个 face 不一定是目标语言或字重。

- 找不到原字体时选择近似字体；不得宣称精确匹配。按用户批准样张延续替代。
- 检查 glyph coverage，包括圆点、圈码、生僻字和数学符号；缺字时用有依据的备用字体并核查其基线、字重和宽度。
- 拉丁数字可能需要单独的字体与数字样式，避免数字重叠或与正文高度不协调。
- CJK 标点保持原来的语义与方向，不全局把全角改成半角。Unicode 正规化不得混淆数学字母、异体字与组合附标。
- 普通正文保留文字对象和 Unicode 映射；不把所有文字转成路径。公式可在保留 LaTeX 源码的条件下使用矢量路径，但必须披露公式的复制限制。
- 嵌入实际使用的字体子集，并在另一渲染器/查看器可用时复查。不要把系统字体完整打包进可分享源文件；列出获取来源和替代配置即可。

## 特殊布局：仅在出现时采用

| 观察到的布局 | 必须保持/处理 | 禁止的捷径 |
| --- | --- | --- |
| 多栏、侧栏、框内正文 | 每栏/框单独区域与阅读顺序，跨栏标题独立 | 全页按 y 排序造成串栏 |
| 环绕图片、非矩形段落 | 多边形文字区与图像排除区；按每条基线计算可用区间 | 用一个大矩形塞字或覆盖图片 |
| 同一行有多个可用区间 | 记录区间顺序并保留间隙，必要时分成行段 | 通过负字距跨越空洞 |
| 圆形、三角形、诗歌、阶梯段落 | 保留行长、缩进、空行及文字形状；逐行比对 | 改成普通两端对齐正文 |
| 沿曲线路径的文字 | 保留路径参数、字向与间距；用支持定位的引擎 | 把曲线文字整体转成普通横排 |
| 竖排、旋转文字、横排夹注 | 区分书写方向与图像旋转；采用正确竖排字形和标点替换 | 逐个横排字简单旋转 90° |
| RTL、连写、组合附标 | 使用 bidi/shaping 引擎，核验视觉与逻辑顺序 | 将每个 Unicode 码点单独定位 |
| 注音、拼音、ruby、上方批注 | 主文与注音建立绑定，独立基线和字号 | 把注音混入主文行距 |
| 首字下沉、大号嵌字 | 下沉字独立对象，周围文字排除其真实墨迹区 | 因它较大而改变全段字号 |
| 页边注、脚注、跨页续注 | 保留标号、分隔线、续接关系与原页位置 | 移到章末或吞并为正文 |
| 名单与对齐姓名 | 按实际列/行排列，保留双字姓名内空与纪念框 | 根据 OCR 顺序丢人、错列，把框当成 I/1 |
| 前景图片、半透明文字叠图 | 保存绘制顺序、裁切和透明度，保护图像内容 | 粗暴白底遮掉整块 |
| 裁切到页边的图文 | 区分原版出血与误裁切，遵从页面框 | 为“留白一致”擅自缩小出血图 |

## 配合误差记录

默认将位置差、行数差、文字溢出、图像位置差、字体替代分别列出。不要把所有差异归为一个“相似度”。位置阈值由有效扫描分辨率和样张决定；可从约 1 point 的主要区域位置误差开始排查，但它是调试起点，不是通用通过标准。

原图字体模糊、纸张歪斜时，清晰字形与逐像素一致会冲突。保留页结构与内容，并明确字体/几何选择，不主动给“像素级完全一致”保证。
