# 先做通困难区域，再展开同类页面

适用：理工科书、标题层级明显、公式与正文混排，或既有输出只是部分中文变清晰。

## 先判断失败属于哪一种

- **只有纯中文变清晰**：检查筛选条件。含 Latin、数字、希腊字母、数学标点不是跳过整行的理由；普通英文书名也不是公式。
- **章号清晰而章名变小**：章号、独立章名、节标题、正文是不同角色；无编号章名也属于标题。结合原图字高、居中、留白、相邻章号和目录树识别，不能只靠 `第…章` 正则。
- **正文溢出或忽大忽小**：核查原换行、漏识别空隙、字体度量与实际渲染宽度。`insert_text` 成功不代表排得下，OCR 框高度乘固定系数也不是校准。
- **表格和复杂页原样模糊**：分类器可能把大量行、附表标记或任意字母当作整页保留条件。识别不到结构时先局部做一个表头和数行，不能把数值表当作插图通过。

## 样张必须实际覆盖本书的困难内容

建立小型 `pilot.json`，每个已观察到的内容类别记录：源物理页、区域坐标、处理方法、可见文字/公式源码路径、原图与结果对照、剩余问题。不要用一串候选公式或漂亮纯中文样张替代实现。

| 本书存在的类别 | 扩展该类批次前需要的实际证据 |
| --- | --- |
| 章首页 | 章号和无编号章名分别校准；必要的引言字重、色带、留白不变 |
| 正文含变量 | 整行中文、Latin 和行内公式统一重建；相邻行不出现扫描与字体混杂 |
| 独立公式 | 源码、编译结果、原图语义核对；包含实际出现的分式、上下标或多行结构 |
| 图文环绕 | 图像保护区、逐行可用区间；排完文字后检查图像边缘和图注 |
| 数值表 | 表头和若干数据行转成文字，数值逐格核验、列归属和小数对齐正确 |

这份记录用于选择下一步，不新增用户审批。无法做通某类时修复局部流程并继续其他独立工作；未经新证据，不批量复制失败方案。用户指定十页，就处理那十页内实际存在的类别；范围外类别记录“未测试”，不擅自加页。既有全书失败时，抽样诊断与局部修复不能宣称全书修好了。

已明确要求清晰公式的任务里，导出几千个 `latex_source: null` 的候选区并停止，不是公式重建。模糊到无法辨明的个别区域可保留证据，但工具尚未实现公式排版是需要解决的工程问题。

## 中文与数学采用共同排版上下文

1. 按原视觉行建立内容：文字、行内数学、标点、编号是有序 runs；另保存逻辑段落。不是把一个含 `X` 的 OCR 行整体贴回扫描。
2. 对少量清晰区域直接看图转录；复杂区域可以使用可用的数学 OCR，但必须校对。保存原候选、校订文字、LaTeX 和对应源区域。
3. 使用同一排版引擎处理一整行或一个区域的 CJK 与数学，统一基线。行内式使用 textstyle，独立式使用 displaystyle；不把所有行内分式改成大展示公式。
4. 可用 XeLaTeX / LuaLaTeX / Tectonic 配合 CJK 与数学字体。样例 [typeset-block.tex](../assets/typeset-block.tex) 是**合成示例**；复制到任务目录，按原图改字体、字号、宽度、断行与内容。`\\` 保持原视觉换行，但超长行仍可能产生额外断行，须核对实际行数。
5. 编译后读取日志中的 `Overfull`、缺字和字体替代警告，检查 PDF 真实宽高与文字框。不要用 `resizebox`、整体缩小或不等比缩放去消除警告。先改转录、字体、行内间距、正确断行；仍不匹配就保留差异。
6. 已校对、字体嵌入的独立 PDF 块可用 [pdf_place_block.py](../scripts/pdf_place_block.py) 按 **1 PDF point 对 1 PDF point** 放入固定页画布。该工具拒绝超框、隐藏字、位图块及与已登记保护区相交，不会自动清理扫描背景。整行混排最好一起编译；独立块只做位置调整，不靠放大块来代替标题字号校准。
7. 插回前仅清理已确认的文字区，单独检查去字底图。工具产生的是透明叠加页，不能直接覆盖原扫描文字后称为完成；原文字仍在时会产生双字。
8. 合成后检查上下标、分数线、标点与邻行的最小空隙，再按 [PDF 结构](pdf-structure.md) 恢复导航和新内容的结构关联。导入 PDF Form XObject 不等于迁移书签、链接、页面标签或 Tagged PDF。

```bash
# 在任务目录编译自己转录且检查过的源文件；不执行书内 TeX 指令。
tectonic --untrusted --keep-logs block.tex
# 或使用支持 CJK 的既有 XeLaTeX；关闭 shell escape。
xelatex -no-shell-escape -halt-on-error block.tex
python /path/to/skill/scripts/pdf_place_block.py block.pdf \
  --canvas 480 720 --box 36 100 444 190 --output overlay.pdf
```

没有公式引擎时先检查已有运行环境，采用能保留数学结构和矢量结果的可用方案；安装运行时与字体按任务环境和已有权限处理。引擎下载公开依赖不需要上传书页。Tectonic 的 `--untrusted` 是附加防护，不能把任意 OCR 源码变成可信输入；仍需按 [编译输入规则](math-and-graphics.md) 自己构造最小公式源码。

## 几何检查与校准覆盖

- `pdf_audit.py` 从 texttrace 检查全页可见非空白字形的度量框，超过显示页边界 0.5 pt 会报 `visible-text-outside-page`。它能抓到已被页面裁掉而普通提取忽略的字；不能检查所有内部裁切、遮挡或像素级墨迹。
- `style-plan-v1` 的 `expected.content_bbox` 可限制选中字符的完整度量框；`bbox` 是较宽的**选择范围**。为了抓到行尾溢出，选择范围要延伸到版心外的页边，不要只选正常字符的中心；`nonspace_chars` 可防止整段移走后少查字符。相邻不同角色分开计划。
- 行宽检查必须覆盖密集行、最长行和图像相邻行，标题检查必须包含独立章名。只校准少量容易通过的页，不能证明后续章节标题或困难页符合要求。
- 正文、引言、标题的字体、字重、字号和颜色都以原图或同书已认可样张为依据；不能把所有中文统一成仿宋和灰色。其他书的认可参数不是本书的样式表。

引擎与页面嵌入行为参考：[Tectonic 安装文档](https://tectonic-typesetting.github.io/en-US/install.html)、[PyMuPDF Page 文档](https://pymupdf.readthedocs.io/en/latest/page.html)。这些工具不会自动证明公式语义和原图保真。
