# PDF 层级和导航

## 分开保存五类结构

| 结构 | 含义与保留方式 |
| --- | --- |
| 标题语义树 | 章/节/小节的父子关系和顺序；排版字体大小不是唯一证据 |
| Outline/书签树 | PDF 阅读器侧栏的层级目录、标题、目标位置、展开状态与样式 |
| PageLabels 与链接 | 印刷页码、PDF 页标签、命名目标、目录点击、注释与脚注跳转 |
| Tagged PDF 结构树 | H1/H2/P/List/Table/Figure 等语义、阅读顺序、ActualText/Alt 与内容引用 |
| OCG/OCMD 及绘制关系 | 可切换内容组的名称、分组、默认可见性与成员；另保留绘制顺序和裁切 |

这些不是同一个东西。一个文件可以有书签但没有标签；有标签也可能只是错误 OCR 建立的结构；扫描的前景/背景分割图像并不自动等于 PDF 可选图层。

## 检查与记录

在重建前导出完整书签树、每个节点的层级/标题/源目标、页面标签定义、选中页链接和批注、命名目标，以及结构树/OCG 的存在性和必要内容。文档级元数据检查不意味着获得转换未授权页内容的权限。

从标题文字、目录页与现有 outline 交叉核查标题语义。发现缺失或错误目录目标时记录原值与证据；不要把原文件中的失效目标原封不动写成“已保留导航”。

## 书签与页码

1. 保持父子关系、顺序、标题与层级，禁止把所有书签压平成一级。
2. 每个节点记录稳定 ID、parent ID、原页号及目标坐标，输出时按页面映射重写目标。
3. 几何变化时目标坐标也要变换；只改页号而不改坐标可能跳到错误位置。
4. 页码显示保持封面/罗马数字前言/正文阿拉伯数字等区段及原来的编号重启，不把文件第 10 页直接标成正文第 10 页。
5. 点击验证顶层与每种深度的节点；对自动修改的目标和边界页逐项验证。检查每个节点的目标范围，不仅抽样数几个书签。
6. 不为了让书签出现而擅自改变阅读器默认视图；原来的展开状态与书签样式尽量保留。

### 仅处理部分页面

输出只包含授权页时，保留范围内节点及必要的祖先容器，正确转换本地目标页号。范围外节点不建立失效的本地跳转；完整原目录保存在源数据中，报告样张目录为子集。

必要祖先的目标不在样张内时，可以保留无跳转的容器，或基于原图证据指向样张内该章节实际起始处；记录选择。不能把全部范围外书签指向第一页。若一个源节点已失效且无法从样张确认，只保留容器并记录待决。

## Tagged PDF 与结构重建

- 存在 `StructTreeRoot` 只能证明存在入口，不能证明标签有效。
- 替换页面内容后，旧 MCID、ParentTree、页面引用与结构元素可能失效。不可仅复制目录字典或设置 `Marked=true` 冒充有效标签。
- 必须让结构元素重新关联新的可见内容，核查标题层级、列表、表格单元格、图像说明和阅读顺序；原有 Alt/ActualText 等经核对保留。
- 保留原隐藏 OCR 的旧标签流，再追加未被标记的新可见字流，不算新内容的标签迁移。旧 OCR 会让提取/复制出现重复正文，而辅助技术仍可能只读旧错字；需要核对新文字的 MCID、ParentTree 和阅读顺序，并去除不需要的重复内容。
- 普通逐字 PDF 绘制脚本通常不会自动生成完整标签。若实现不能维护既有标签，切换到支持标签的生成路径或将结构迁移列为未完成；不得在“保留 PDF 层级结构”的任务中静默丢弃。
- 原文件未带标签时，至少保留标题树、有效书签与逻辑源文件；若用户明确要求 Tagged PDF/无障碍结构，则必须生成并另做验证，不能仅交书签。

## 链接、批注和图层

- 链接矩形随文字位置变换，内部目标随页面映射变换；外部 URI 原样保留有效目标，不自动访问。
- API 返回的 Launch/GoToR/Named 动作也要登记；例如印刷网址可能被错误编码为 `file:` URI，并被库返回为文件动作。不能只检查 HTTP URI 和页内 GoTo 而漏掉这些链接，也不能执行动作来验证。读取原始字典，按可见原文证据修复错误并记录。
- 页复制、内容嵌入或 `show_pdf_page` 等操作不应被假定会复制链接、批注和文档目录。重新检查并在交付 PDF 中恢复所需结构。
- 书中注释、印章和用户批注不可作为噪点删除；保留外观和其锚点关系。样张范围外目标应登记，不设失效跳转。
- OCG 需保持组关系、开关状态和内容成员；新正文应归入对应组。把全部内容烧录进位图会失去开关功能。
- 切换相关图层核验内容仍正确，并检查默认状态；单次默认渲染不足以验证图层保留。

## 结构验收

保存迁移前后目录树，按 parent、title、destination 比对；检查页面标签；逐项记录链接迁移；检查结构树内容引用与图层状态。不得以节点总数相同或入口字典存在替代语义和目标验证。

随附 `pdf_audit.py` 能发现常见书签缺失、映射不符、结构入口丢失等问题，但不能证明标签内部、任意命名目标、OCG 成员或全部跳转正确。脚本报告后仍要进行上述检查。
