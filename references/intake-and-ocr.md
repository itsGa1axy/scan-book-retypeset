# 输入检查与 OCR

## 先确认页面事实

记录输入摘要与 SHA-256、页数、请求页序、打印页码、MediaBox/CropBox、rotation、是否加密、每页图像的实际放置矩阵及像素尺寸。

- “数字版”可能只是扫描图加隐藏 OCR；必须同时查看渲染和文字绘制模式。
- 有文本对象不代表肉眼看到的是文本：文字可能透明、在图后、用来裁切、脱离可见区域或仅是页码。
- 无文本也不等于空白：可能是文字转曲、扫描页、纯插图或渲染异常。先看页面。
- 密码不可读取时明确缺少读取条件；不反复尝试空密码或把提取失败记为空页。
- 同一文件可混合原生文字、图片、OCR 和转曲页面，分类到区域而非只给整书一个标签。
- 正反面空白、插页、折页和前置目录可能改变打印页码偏移，禁止假定全书有唯一固定偏移。

`pdf_probe.py` 的分类是排查线索；`get_texttrace()` 的绘制模式不能排除后续遮盖，提取图像清单也不能证明图层在视觉上独立。

## 分流

| 实际证据 | 处理 |
| --- | --- |
| 字体清晰、文字抽取正确、位置可靠 | 重用原生文本/矢量，检查嵌入与编码 |
| 扫描页上已有隐藏 OCR | 取其文字与坐标作候选，逐页对照、修正遗漏和错序 |
| 扫描无 OCR | 对授权范围做 OCR，要求 bbox/quad、行和置信度；没有置信度就填 null |
| 文本转曲 | 保留正确的矢量图形；需可复制的正文另做识别与字体重建 |
| 混合分辨率/掩模 MRC 图层 | 先合成看图，分清背景、前景、掩模和真实插图 |
| 低清、折痕、失焦、反光、手写批注 | 分区处理，保留原图证据，不能根据上下文补字 |

## OCR 与校订

1. 从原文的语言、繁简、书写方向和字形选择识别路径。默认先用已有本地能力；更强引擎只用于确实有问题的区域。
2. 渲染分辨率根据最小字与原图实际信息决定。可从约 300 dpi 试起；放大插值不等于恢复信息，不得以 600 dpi 输出声称识别必然更准。
3. 先识别栏和区域，再按区域识别行。隔栏、图注、脚注、侧栏和公式编号不能混进正文顺序。
4. 保存 OCR 原文、bbox/quad、引擎与版本、输入裁片坐标。分块 OCR 必须记录页面原点偏移及缩放。
5. 人工/视觉检查段落起止、行末、标题、表格单元格、名单、人名与小字号；对无 OCR 的区域核查是装饰还是漏识别。
6. 只用原图证据修正。同音字、常用姓名、历史知识和语法通顺都不能替代字形证据；若借同书重复文字辨认，记录对应页，仍核对本处。
7. 原书文字含拼写错误时原样保留，另记疑点。不要把 OCR 修正和编辑校勘混为一谈。

对 OCR 完全漏掉的人名，补齐“人数”不等于补对文字。单独裁片放大到可辨认笔画，逐字检查偏旁与上下结构，再核验补入后的渲染；仍看不清时登记不确定，不能创造一个看似合理的名字。

常见易错内容：0/O/〇、1/l/I/Ⅰ、rn/m、简繁异体、人名生僻字、负号/破折号、乘号/x、点号/小数点、全角标点、引号方向、①与图标、框线与字母 I、公式上下标及单位。

## 分割图层的限制

MRC 背景可能残留模糊字影；前景色块不等于可独立提取的插图。先渲染完整页面验证合成。只有证明图像资源确实独立时才原样提取资源。

从扫描页取插图通常是裁切原扫描；这不是恢复原始出版图像。保持源像素，不重新生成、锐化或调色。记录裁切矩形/多边形、透明掩模、变换和输出放置区域。

## 摄影页面与几何

- 旋转、透视、弯曲、书脊遮挡和双页跨幅分别处理，不能只应用一个旋转角就声称矫正完成。
- 默认局部矫正仅用于识别；最终页面位置仍映射回原版坐标。
- 若最终页面也做展平，要明确图像是否允许同样变形。用户要求图片原位原形时，不自动把图片一起拉伸。
- 双页扫描拆分会改变页数；先解释实际映射，并在已授权方案内处理。中缝跨页图片需要保留完整内容，不从任一侧重复裁掉。
- 阴影或污点与笔画重合时不进行凭空修复，记录不可辨认区域。

## 持续处理长书

按页批次存储产物和状态，每批结束记录成功、失败与待复核页。恢复时核对输入摘要和配置版本；不要重复 OCR 已验证页，也不要跳过失败页。共享样式修改须标记受影响批次重新校验。

本工作流无需把书上传网络；需要云 OCR 时只上传已授权范围，记录服务、页码和返回文件。不得为校订去寻找并替换成其他版本的整本电子书。

## 隐藏 OCR 的样式污染

OCR 字号、字体名与颜色只能当候选。整行文本很相似不代表字形、标点、遗漏姓名或字重正确；第二引擎与原 OCR 的高相似度不是对照原图的替代。输出有文字候选时，仍检查其是否覆盖每个应重建区域，并单独检查底图里是否残留未被识别的正文。
