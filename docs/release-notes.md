# v1.2.0

本轮针对数学教材抽查发现的公式与混排仍为扫描、独立章名过小、行尾裁字迭代。

- 新增困难区域样张流程：按实际内容验证后再扩展同类批次，不能用候选公式索引代替排版。
- 提供合成 CJK/LaTeX 模板与 `pdf_place_block.py`，以自然尺寸放置编译后的可见文字与公式，拒绝超框和保护区相交。
- `pdf_audit.py` 检查全页字符越界；样式计划增加可选 `expected.content_bbox`。
- 保留书签父子关系、页面映射、标签迁移和逐页证据要求。

辅助工具不自动 OCR、清理扫描或证明数学语义。局部书页验证不能当作全书修复；公开包不包含书页或系统字体。LaTeX 引擎和 CJK 字体是可选外部依赖。
