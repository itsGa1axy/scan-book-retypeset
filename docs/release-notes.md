# v1.0.0 · 扫描书籍同版重建

将扫描书重建为清晰可见的排版文字，保留图片、特殊布局、分页与 PDF 层级。

- 17 条核心质量约束，8 份详细参考。
- 章节与书签父子关系、页面标签、内部链接、标签结构及可选图层分别验收。
- 提供 PDF 探查、逐页对照和有限结构审核工具。
- 自建 PDF 的 25 个 CLI 回归场景，另含安装及确定性打包测试。

下载 `scan-book-retypeset-v1.0.0.zip`，解压后将完整目录放入 agent 的 skills 目录；用 `SHA256SUMS` 校验下载文件。

本项目是 agent 工作流及辅助检查工具，不是自动 OCR 或一键整书转换器。复杂公式语义和标签内部迁移仍需逐页验证。
