# v1.1.0 · 样式校准与严格交付门禁

修复真实使用中暴露的流程缺口：名单字号膨胀、标题混色、引文字体错误，以及检查失败仍宣称完成。

- 先按原图/认可样张校准语义角色，再扩展批次；OCR 字号和字体不直接进入正式样式。
- 新增区域样式检查，检测字号、字体、颜色与可选可见字符数量差异。
- 新增交付门禁，重跑当前 PDF 的审核和样式检查，要求摘要绑定的逐页全景/细节证据及新内容标签验证。
- 旧隐藏 OCR 的标签入口、全书联系表和泛化例外说明不能替代完整重建与逐页复核。
- 增加自建 PDF 回归测试；失败实书输出被拒绝，已认可样张的四类校准区域通过。

下载 `scan-book-retypeset-v1.1.0.zip`，保留整个目录安装；ZIP 与 `SHA256SUMS` 一同提供。

兼容性：原有探查/对照/审核命令保留。新增完成验收采用 `review-v2` 和独立样式计划，旧自由文本 review-v1 需补齐证据。门禁通过仅表示有限检查和记录一致，不证明 OCR、视觉或标签内部正确。
