# 验证范围

## 自动验证

- `tools/validate_skill.py` 检查必需 frontmatter、命名、版本、相对资源链接和 JSON 模板。
- 官方 `skills-ref validate` 可额外验证 Agent Skills 格式；官方规范与来源见 [standards.md](../references/standards.md)。本地检查器并非官方认证。
- `tests/test_cli.py` 实际运行 25 个 CLI 场景：原文件 SHA-256 不变、重复/越界/反向页序、输出防覆盖与硬链接别名、空白页例外、页数/尺寸差异、可见字体、隐藏文字位图、缺失/扁平/错误目标书签、页标签、URI/页内/特殊动作链接丢失、部分页祖先映射和结构入口丢失。
- `tests/test_distribution.py` 验证安装拒绝覆盖、必要资源完整、确定性打包与校验和。
- 所有测试 PDF 在临时目录生成，不依赖用户书籍或本机字体。

## 真实样张经验

早期十页样张用于视觉复核；复核纠正过姓名识别和书脊括号方向，也发现原样张未迁移全部导航及标签结构。由此增加了明确的结构验收要求。该样张不作为完整结构迁移的成功证明，也不随本项目发布。

## 未覆盖的证明

上述检查不能证明 OCR 完全正确、复杂公式语义正确、所有图片像素一致、Tagged PDF 的 MCID / ParentTree 引用有效、任意命名目标可用或 OCG 成员完整。公式、竖排、异形布局等规则尚未全部做端到端书页试验。

审核退出码 0 表示有限检查未发现差异，仍需逐页内容、视觉和导航复核。具体完成门槛见 [quality-gates.md](../references/quality-gates.md)。
