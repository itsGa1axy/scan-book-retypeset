# 验证范围

## 自动验证

- `tools/validate_skill.py` 检查必需 frontmatter、命名、版本、相对资源链接和 JSON 模板。
- 官方 `skills-ref validate` 可额外验证 Agent Skills 格式；官方规范与来源见 [standards.md](../references/standards.md)。本地检查器并非官方认证。
- `tests/test_cli.py` 实际运行 25 个 CLI 场景：原文件 SHA-256 不变、重复/越界/反向页序、输出防覆盖与硬链接别名、空白页例外、页数/尺寸差异、可见字体、隐藏文字位图、缺失/扁平/错误目标书签、页标签、URI/页内/特殊动作链接丢失、部分页祖先映射和结构入口丢失。
- `tests/test_distribution.py` 验证安装拒绝覆盖、必要资源完整、确定性打包与校验和。
- 所有测试 PDF 在临时目录生成，不依赖用户书籍或本机字体。

## v1.1 验证

- 新增 `tests/test_quality_gates.py` 的 34 项行为测试，完整套件共 41 项测试（其中旧 CLI 套件实际覆盖 25 场景），使用临时 PDF 检查校准通过与字号/字体/颜色/字符数量异常，并验证交付记录不能绕过隐藏文字、缺失证据或标签迁移要求。
- 同一源书的用户认可十页样张与被拒绝的整书输出，采用相同角色校准依据。名单、章节标题、引文、页眉四个区域：认可样张通过；失败输出被查出字号、字体、颜色及可见字数量差异。
- 失败整书的旧复核报告即使自称完成，也被新的交付门禁拒绝。真实 PDF、书页裁片及私人路径不发布到仓库。
- 这不是一次完成整本书重建的验证；只验证新规则与工具能发现已观测的失败，并有合格自建实例通过。

## 真实样张经验

早期十页样张用于视觉复核；复核纠正过姓名识别和书脊括号方向，也发现原样张未迁移全部导航及标签结构。由此增加了明确的结构验收要求。该样张不作为完整结构迁移的成功证明，也不随本项目发布。

## 未覆盖的证明

上述检查不能证明 OCR 完全正确、复杂公式语义正确、所有图片像素一致、Tagged PDF 的 MCID / ParentTree 引用有效、任意命名目标可用或 OCG 成员完整。公式、竖排、异形布局等规则尚未全部做端到端书页试验。

审核退出码 0 表示有限检查未发现差异，仍需逐页内容、视觉和导航复核。具体完成门槛见 [quality-gates.md](../references/quality-gates.md)。

## v1.2 验证

新增 `tests/test_composition.py` 的 11 项真实 PDF 回归，完整套件共 52 项测试（另含旧 CLI 的 25 场景）。覆盖自然尺寸与 Unicode/字体保留、过宽/过高拒绝、保护区相交、隐藏/位图/旋转/已溢出块拒绝、输入与已有输出保护、非有限坐标、全页裁字和列内行尾越界。可选内容框不改变旧样式计划的检查结果。

实际抽查覆盖章首页、变量混排、分式、复杂公式、二维码环绕和数值表。失败输出中的页外文字被新增检查发现。自动回归使用合成文件；本地书页验证与源码不会进入公开仓库。CJK/TeX 模板需用户环境有可用字体与引擎，CI 不安装大型 TeX 运行时；数学语义、表格整页转换和原书全部页面未因此得到自动证明。

本轮本地还实际编译并放回两处修复区域：独立章名、中文/变量混排及首个分式；另编译合成求和/分式模板。查看了局部三方对照与整页预览，核查对应子集的三级书签和页标签。去字后保留原 DeviceGray 解释，并验证修补区外解码像素及高倍率渲染一致；低倍率 JPEG/无损图像渲染仍可能有细微边缘差异。这只证明这些局部实现，未重建全书、数值表或全部复杂公式。
